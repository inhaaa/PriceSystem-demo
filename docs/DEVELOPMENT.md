# 개발 안내

## 원본 작업과 공개 데모의 구분

이 저장소는 실제 완성된 운영 시스템을 소개하기 위한 별도 데모입니다. 아래 날짜는 원본 개발 작업에서 확인한 모듈 단위 기록이며, 공개 데모의 완료일이나 배포 실적을 뜻하지 않습니다.

| 날짜 | 원본 개발 작업의 모듈 단위 기록 |
| --- | --- |
| 2026-06-19 | 통합 데이터 구조 테스트 |
| 2026-09-18 | 기능 모듈과 import 검증 구성 정리 |
| 2026-09-21 | DB 스키마 추출 |

공개 데모는 가상 샘플, 세션별 메모리 저장소, 공개 데모 로그인, 고정된 분석·API 샘플을 사용합니다. 실제 분석 로직, 업무 데이터, 운영 환경 설정은 이 저장소의 개발 대상이 아닙니다.

## 개발 환경

Python 3.11 이상과 `requirements.txt`에 고정된 의존성을 사용합니다. 별도 가상환경에 설치하는 방법은 [README](../README.md#빠른-시작)를 참고하세요.

가상환경을 활성화한 상태에서 실행합니다.

```bash
python -m streamlit run app.py
```

추가 서비스, API 키, 외부 DB는 필요하지 않습니다.

## 모듈별 변경 위치

| 변경 목적 | 먼저 확인할 위치 |
| --- | --- |
| 공고·투찰·결과·분류 데이터의 계약과 CRUD | `demo/store.py` 및 관련 테스트 |
| 초기 가상 데이터 | `demo/samples.py` |
| 고정 분석·API 샘플, 데모 계정 확인 | `demo/services.py` |
| 공통 화면 표현 | `demo/ui.py` |
| 기존 메뉴·그룹·업무 탭·홈 구성 | `demo/workspace.py` |

데이터 필드나 CSV 형식을 바꿀 때는 저장소의 스키마·입력 계약을 먼저 확인합니다. 샘플, 템플릿, 입력 폼이 같은 계약을 사용하도록 변경하고 기존 CRUD 및 초기화 흐름을 확인합니다. 가상 이름·기관·금액·일정만 사용하며 실제 자료를 샘플로 옮기지 않습니다.

## 검증

가상환경을 활성화한 뒤 표준 라이브러리 테스트 러너로 실행합니다.

```bash
python -m unittest discover -s tests -v
```

테스트는 해당 실행 결과로 확인합니다. 이 문서는 테스트 통과, 배포 완료, 운영 성능을 인증하는 기록이 아닙니다.

화면 변경 후에는 다음 흐름을 직접 확인합니다.

1. 데모 로그인 후 홈과 각 탭이 열리는지 확인합니다.
2. 가상 공고를 추가·수정·삭제하고 연관 화면에 반영되는지 확인합니다.
3. 기존 자료 등록의 하위 탭에서 샘플을 불러와 선택 등록하고 처리 이력을 확인합니다.
4. 분석·추천 및 API 화면에 시연용 샘플이라는 표시가 있는지 확인합니다.
5. 샘플 초기화·로그아웃·새 세션에서 기본 샘플로 시작하는지 확인합니다.

## 다음 개선의 기준

개선은 데모 체험 중 확인되는 불편을 기준으로 진행합니다. 접근성 점검, 입력 오류 안내, CSV 형식 설명 보완을 우선 검토할 수 있습니다. 실제 인증, 영구 저장, 외부 API 연결, 분석 엔진 도입은 별도 요구사항·권한·데이터 정책을 먼저 정해야 하는 범위입니다.

시각 자산을 추가하거나 재사용하기 전에는 [자산 및 권리 안내](../ASSET_NOTICE.md)를 확인합니다.
